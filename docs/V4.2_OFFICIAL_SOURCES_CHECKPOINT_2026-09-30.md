## Implemented

### CVM Open Data

Implemented `src/b3_agent/providers/cvm_open_data.py`:

- IPE annual public dataset for history/backfill/reconciliation;
- company CAD dataset for CVM code/CNPJ/legal identity;
- FCA `valor_mobiliario` dataset for official CNPJ -> trading-code mapping;
- Latin-1 / UTF-8 handling;
- normalized field names;
- deterministic IPE provider record IDs;
- separation of `Data_Referencia` and `Data_Entrega`;
- CVM local date/time normalization using `America/Sao_Paulo`.

The public IPE lane is explicitly marked as historical reconstruction. It does not pretend to reproduce live first-seen timing.

### Issuer Registry

Implemented `src/b3_agent/intelligence/issuer_registry.py`.

Canonical deterministic relationships:

```
CVM code / CNPJ
       |
       v
     Issuer
       |
       +----> Security / ticker 1
       +----> Security / ticker 2
       +----> ...
```

The registry never asks an LLM to infer issuer identity or ticker relationships.

SQLite structured state:

- `issuers`
- `securities`
- `issuer_registry_sync_runs`

Default location:

- `$B3_AGENT_DATA_DIR/structured/issuer_registry.sqlite3`

### Canonical official Evidence

Implemented `src/b3_agent/intelligence/official_evidence.py`.

Both official lanes normalize into the existing V4 `Evidence` contract:

```
CVM RAD -------------------+
                           |
                           v
                    canonical Evidence
                           ^
                           |
CVM Open Data IPE ---------+
```

No second Evidence model was introduced.

Open Data IPE Evidence:

- source class: `OFFICIAL_REGULATORY`
- authority tier: `0`
- discovery channel: `CVM_OPEN_DATA`
- PIT status: `HISTORICAL_RECONSTRUCTION`
- `Data_Referencia` -> `reference_at`
- `Data_Entrega` -> historical delivery/publication date semantics
- `first_seen_at` -> actual reconstruction retrieval time
- delivery precision retained in metadata
- issuer and ticker refs populated from Issuer Registry

RAD Evidence:

- source class: `OFFICIAL_REGULATORY`
- authority tier: `0`
- discovery channel: `CVM_RAD`
- PIT status: `OBSERVED_LIVE`
- no invented publication timestamp
- `first_seen_at` and `observed_at` come from actual provider retrieval

### Deterministic official materiality

Existing V4.2 rules are reused before any LLM:

- Fato Relevante -> `MATERIAL / OFFICIAL_FATO_RELEVANTE`
- Comunicado ao Mercado -> `CANDIDATE`
- Aviso aos Acionistas -> `CANDIDATE`
- other official items -> deterministic lower classification

### Historical real-event reasoning replay

Implemented:

- `scripts/replay_v42_official_fact.py`

The replay:

1. resolves a real issuer/ticker;
2. reads a real historical IPE record;
3. requires deterministic `MATERIAL / OFFICIAL_FATO_RELEVANTE`;
4. rejects synthetic evidence;
5. runs local DeepSeek;
6. escalates to OpenClaw/Luna;
7. rejects unknown evidence refs;
8. writes an auditable replay artifact.

This is the mandatory reasoning acceptance track independent of live-day event randomness.
